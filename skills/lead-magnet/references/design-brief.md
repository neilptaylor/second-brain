# Design Brief Template — Canva / Nano Banana / Designer

Every lead magnet ships with a design brief. This is the document Neil (or a freelance designer, or a Nano Banana prompt) uses to turn the `.docx` into a beautiful, on-brand PDF or carousel.

Keep it one page. Keep it scannable. No pretty paragraphs — this is instructions.

---

## Template

```
# Design Brief — [Lead Magnet Title]

## Format
- Output: PDF / Instagram carousel / single printable page / carousel + cover
- Size: A4 portrait / 1080x1350 / letter
- Page count: [N] pages

## Tone & Mood
- One-word mood: [warm / still / quiet / tender / grounded]
- Reference image vibe: [domestic-photography / film-still / kitchen-table-documentary]
- NOT this: [stock business / grinning families on laptops / over-saturated / corporate]

## Palette (from Brand Guidelines)
- Primary: [hex]
- Secondary: [hex]
- Accent: [hex]
- Background: [cream / off-white — never pure white]

## Typography (from Brand Guidelines)
- Headline font: [e.g. serif display]
- Body font: [e.g. clean sans]
- Use size contrast, not weight-stacking, to build hierarchy.

## Page Map
- **Page 1 — Cover.** Big headline. One-line promise underneath. A small "Me & My Old Man" mark bottom-right.
- **Page 2 — Intro.** All text. Generous white space. The intro from the .docx.
- **Page 3-N — Body.** One idea per page where possible. Each body page has: section title, 2-4 lines of body, and either a try-this prompt or a reflection question in a quiet callout.
- **Page N-1 — Closing reflection.** Mostly white space. One quiet line at the centre.
- **Page N — CTA + About.** Soft CTA and the 75-word About paragraph.

## Imagery
- [Per page, specify: photograph / illustration / text-only / pull-quote / none]
- Default: mostly text-and-white-space. Add imagery only where it earns its keep.

## Nano Banana / Midjourney Prompts (if originals needed)
1. [Prompt — scene, mood, lighting, composition. Always specify no stock-photo feel, real-life texture, domestic interior.]
2. [Prompt]
3. [Prompt]

## Hard Rules
- No stock smiley families.
- No gradient backgrounds.
- No more than 2 fonts across the whole asset.
- No icons for decoration — icons only if they carry meaning.
- Plenty of white space. A cramped page kills the tone.
- Cover headline max 8 words.
- Body font size big enough to read on a phone without pinching.

## Accessibility
- Contrast ratio: AA minimum.
- Heading hierarchy maintained for PDF readers.
```

---

## How to Write the Nano Banana / Midjourney Prompts

Neil is using image generation to produce bespoke visuals that don't look like stock photography. Each prompt should contain:

1. **Scene** — "a father and adult son at a kitchen table, mid-conversation, late afternoon light"
2. **Mood** — "quiet, warm, slightly wistful"
3. **Style** — "shot on film, grain, natural colour, soft focus background"
4. **Negatives** — "no smiles to camera, no posed look, no laptop or phone visible, no branded clothing"

The test for a good prompt: if you read it out loud, can you picture the photograph? If not, rewrite.

---

## A Note for Claude

When you fill in this template for a specific lead magnet, *do not* include generic filler. If a section doesn't apply, delete it. Better to ship a shorter brief that answers only the questions that matter for this asset.

The design brief should fit on one page when printed. If it runs to two — cut.
