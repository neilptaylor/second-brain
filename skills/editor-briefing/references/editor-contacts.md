## General rules for all editors
- Always link the actual editor briefing doc created in Step 2, using "is
  here" or "here" as the link text, matching Neil's established pattern.
- Keep the email short — this is a handoff notification, not a briefing
  restatement. The doc carries the detail.
- Draft only — never send. Neil reviews and sends himself.
- If the editor for a session isn't one of the three above, don't guess a
  style — draft a minimal version (greeting, doc link, "please confirm
  receipt", sign-off) and flag to Neil that this editor has no saved style
  yet.
